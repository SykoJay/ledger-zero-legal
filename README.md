# LEDGER//ZERO™ legal pages

Public EULA and privacy policy drafts for GitHub Pages. **Complete all square-bracket placeholders and review the actual production data handling before publishing.** This is a drafting aid, not legal advice.

## Publish
1. Create a separate **public** repository named `ledger-zero-legal`.
2. Upload `index.html`, `eula.html`, and `privacy.html` to the repository root.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.
4. Visit `https://YOUR-GITHUB-USERNAME.github.io/ledger-zero-legal/eula.html` and `https://YOUR-GITHUB-USERNAME.github.io/ledger-zero-legal/privacy.html` and verify both return real pages.
5. Enter the verified URLs in the Intuit Production app details.

Do **not** publish OAuth credentials, actual company financial records, or private application source here.
